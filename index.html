FAQ

Questions parents usually ask first.

Still unsure? Just call +91 62805 54348 — Divya or Tejasvi will pick up between classes.

Each batch is capped at twenty students. Senior science batches are usually smaller — because the syllabus deserves it. We don't run classes of thirty.

Primarily CBSE, since most students come from schools in Panchkula and Mohali. We comfortably support ICSE for Class VI–X — please mention the board when you enquire so we can plan reference material.

Yes — a full, unhurried demo class is free. We prefer the child sit in on a regular session rather than a special one, so they see exactly what the everyday looks like.

We run a hybrid Class XI–XII Biology batch on Zoom for students who have moved cities mid-session. Junior classes are in-person only — at that age, the room matters.

Weekly chapter tests on Saturday, a monthly cumulative test, and a printed report card every term that we hand to parents personally. We're not big on WhatsApp updates — we'd rather have a real conversation.

Fees are charged monthly — no large one-time deposits. If a student leaves mid-month for any reason, the unused portion is refunded, pro-rata.
